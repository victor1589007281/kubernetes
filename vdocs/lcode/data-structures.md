## 数组

### 核心知识点

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                            数组常见技巧                                      │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│   1. 双指针                                                                  │
│   ┌─────────────────────────────────────────────────────────────────┐       │
│   │  • 相向双指针: 两数之和II、盛水容器、三数之和                    │       │
│   │  • 同向双指针: 移动零、删除重复项                                │       │
│   │  • 快慢指针: 寻找重复数                                          │       │
│   └─────────────────────────────────────────────────────────────────┘       │
│                                                                              │
│   2. 前缀和                                                                  │
│   ┌─────────────────────────────────────────────────────────────────┐       │
│   │  prefix[i] = sum(nums[0..i-1])                                  │       │
│   │  区间和 [i,j] = prefix[j+1] - prefix[i]                         │       │
│   │                                                                  │       │
│   │  应用: 和为K的子数组、连续数组                                   │       │
│   └─────────────────────────────────────────────────────────────────┘       │
│                                                                              │
│   3. 差分数组                                                                │
│   ┌─────────────────────────────────────────────────────────────────┐       │
│   │  diff[i] = nums[i] - nums[i-1]                                  │       │
│   │  区间加: diff[l] += val, diff[r+1] -= val                       │       │
│   │                                                                  │       │
│   │  应用: 航班预订统计、拼车                                        │       │
│   └─────────────────────────────────────────────────────────────────┘       │
│                                                                              │
│   4. 原地修改                                                                │
│   ┌─────────────────────────────────────────────────────────────────┐       │
│   │  利用数组本身存储信息，避免额外空间                              │       │
│   │  常用技巧: 取负标记、模运算编码                                  │       │
│   │                                                                  │       │
│   │  应用: 找到消失的数字、第一个缺失的正数                          │       │
│   └─────────────────────────────────────────────────────────────────┘       │
│                                                                              │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 前缀和详解

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                          前缀和原理                                          │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│   原数组:    [1, 2, 3, 4, 5]                                                │
│   前缀和:  [0, 1, 3, 6, 10, 15]                                             │
│              ↑                                                              │
│           prefix[0]=0 方便计算                                              │
│                                                                              │
│   区间和 [1,3] = 2+3+4 = 9                                                  │
│                = prefix[4] - prefix[1]                                      │
│                = 10 - 1 = 9 ✓                                               │
│                                                                              │
│   ┌─────────────────────────────────────────────────────────────────┐       │
│   │  560. 和为K的子数组                                              │       │
│   │                                                                  │       │
│   │  prefix[j] - prefix[i] = k                                      │       │
│   │  → prefix[i] = prefix[j] - k                                    │       │
│   │                                                                  │       │
│   │  用哈希表记录每个前缀和出现的次数                                │       │
│   │  遍历时查找 prefix[j] - k 出现的次数                            │       │
│   └─────────────────────────────────────────────────────────────────┘       │
│                                                                              │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 链表

### 核心知识点

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                            链表常见技巧                                      │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│   1. 虚拟头节点 (Dummy Node)                                                 │
│   ┌─────────────────────────────────────────────────────────────────┐       │
│   │  dummy → [1] → [2] → [3] → nil                                  │       │
│   │                                                                  │       │
│   │  优点: 统一处理头节点的边界情况                                  │       │
│   │  应用: 删除节点、合并链表、反转链表                              │       │
│   └─────────────────────────────────────────────────────────────────┘       │
│                                                                              │
│   2. 快慢指针                                                                │
│   ┌─────────────────────────────────────────────────────────────────┐       │
│   │  slow (1步)   fast (2步)                                        │       │
│   │    ↓            ↓                                                │       │
│   │  [1] → [2] → [3] → [4] → [5]                                   │       │
│   │                                                                  │       │
│   │  应用:                                                           │       │
│   │  • 找中点: fast到末尾时，slow在中点                              │       │
│   │  • 检测环: 有环则快慢指针必相遇                                  │       │
│   │  • 找环入口: 相遇后从头和相遇点同速前进                          │       │
│   └─────────────────────────────────────────────────────────────────┘       │
│                                                                              │
│   3. 反转链表                                                                │
│   ┌─────────────────────────────────────────────────────────────────┐       │
│   │  迭代: prev, curr, next 三指针                                   │       │
│   │  递归: 先递归到末尾，再回溯修改指针                              │       │
│   │                                                                  │       │
│   │  应用: 反转整个链表、反转区间、K个一组反转                       │       │
│   └─────────────────────────────────────────────────────────────────┘       │
│                                                                              │
│   4. 合并/分解                                                               │
│   ┌─────────────────────────────────────────────────────────────────┐       │
│   │  合并两个有序链表: 迭代或递归                                    │       │
│   │  合并K个有序链表: 分治或堆                                       │       │
│   │  分解: 奇偶分离、按值分区                                        │       │
│   └─────────────────────────────────────────────────────────────────┘       │
│                                                                              │
└─────────────────────────────────────────────────────────────────────────────┘
```

```
│   │                                                                  │       │
│   │  滑动窗口最大值:                                                 │       │
│   │  队首始终是当前窗口最大值的索引                                  │       │
```

### 单调栈模板

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                          单调栈模板                                          │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│   问题: 找每个元素的下一个更大元素                                          │
│                                                                              │
│   nums = [2, 1, 2, 4, 3]                                                    │
│   ans  = [4, 2, 4,-1,-1]                                                    │
│                                                                              │
│   func nextGreaterElement(nums []int) []int {                               │
│       n := len(nums)                                                        │
│       ans := make([]int, n)                                                 │
│       stack := []int{} // 存索引                                            │
│                                                                              │
│       // 从右向左遍历 (或从左向右，逻辑稍有不同)                            │
│       for i := n - 1; i >= 0; i-- {                                         │
│           // 弹出所有小于等于当前元素的栈顶                                  │
│           for len(stack) > 0 && nums[stack[len(stack)-1]] <= nums[i] {      │
│               stack = stack[:len(stack)-1]                                  │
│           }                                                                  │
│                                                                              │
│           // 栈顶就是下一个更大元素                                          │
│           if len(stack) == 0 {                                              │
│               ans[i] = -1                                                    │
│           } else {                                                           │
│               ans[i] = nums[stack[len(stack)-1]]                            │
│           }                                                                  │
│                                                                              │
│           stack = append(stack, i)                                          │
│       }                                                                      │
│       return ans                                                             │
│   }                                                                          │
│                                                                              │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 图

### 核心知识点

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                            图的遍历                                          │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│   1. DFS (深度优先搜索)                                                      │
│   ┌─────────────────────────────────────────────────────────────────┐       │
│   │  func dfs(node, visited) {                                      │       │
│   │      if visited[node] { return }                                │       │
│   │      visited[node] = true                                       │       │
│   │      for neighbor := range graph[node] {                        │       │
│   │          dfs(neighbor, visited)                                 │       │
│   │      }                                                          │       │
│   │  }                                                              │       │
│   │                                                                  │       │
│   │  应用: 岛屿数量、路径搜索、连通分量                              │       │
│   └─────────────────────────────────────────────────────────────────┘       │
│                                                                              │
│   2. BFS (广度优先搜索)                                                      │
│   ┌─────────────────────────────────────────────────────────────────┐       │
│   │  queue := []int{start}                                          │       │
│   │  visited[start] = true                                          │       │
│   │  for len(queue) > 0 {                                           │       │
│   │      node := queue[0]; queue = queue[1:]                        │       │
│   │      for neighbor := range graph[node] {                        │       │
│   │          if !visited[neighbor] {                                │       │
│   │              visited[neighbor] = true                           │       │
│   │              queue = append(queue, neighbor)                    │       │
│   │          }                                                      │       │
│   │      }                                                          │       │
│   │  }                                                              │       │
│   │                                                                  │       │
│   │  应用: 最短路径、层级遍历                                        │       │
│   └─────────────────────────────────────────────────────────────────┘       │
│                                                                              │
│   3. 拓扑排序                                                                │
│   ┌─────────────────────────────────────────────────────────────────┐       │
│   │  处理有向无环图 (DAG) 的依赖关系                                 │       │
│   │                                                                  │       │
│   │  Kahn 算法:                                                      │       │
│   │  1. 计算所有节点入度                                             │       │
│   │  2. 入度为0的节点入队                                            │       │
│   │  3. 出队节点，减少邻居入度，新入度为0则入队                      │       │
│   │                                                                  │       │
│   │  应用: 课程表、任务调度                                          │       │
│   └─────────────────────────────────────────────────────────────────┘       │
│                                                                              │
│   4. 并查集                                                                  │
│   ┌─────────────────────────────────────────────────────────────────┐       │
│   │  高效处理连通性问题                                              │       │
│   │  操作: Find(查找根)、Union(合并)                                 │       │
│   │  优化: 路径压缩、按秩合并                                        │       │
│   │                                                                  │       │
│   │  应用: 连通分量、冗余连接、等式方程                              │       │
│   └─────────────────────────────────────────────────────────────────┘       │
│                                                                              │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 堆

### 核心知识点

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                            堆的应用                                          │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│   堆的性质:                                                                  │
│   ┌─────────────────────────────────────────────────────────────────┐       │
│   │  大顶堆: 每个节点 >= 子节点                                     │       │
│   │  小顶堆: 每个节点 <= 子节点                                     │       │
│   │                                                                  │       │
│   │  时间复杂度:                                                     │       │
│   │  • 插入: O(log n)                                               │       │
│   │  • 删除堆顶: O(log n)                                           │       │
│   │  • 获取堆顶: O(1)                                               │       │
│   │  • 建堆: O(n)                                                    │       │
│   └─────────────────────────────────────────────────────────────────┘       │
│                                                                              │
│   常见应用:                                                                  │
│   ┌─────────────────────────────────────────────────────────────────┐       │
│   │  1. Top K 问题                                                   │       │
│   │     • 第K大元素: 小顶堆维护K个最大元素                          │       │
│   │     • 前K个高频元素: 小顶堆 + 哈希计数                          │       │
│   │                                                                  │       │
│   │  2. 合并K个有序链表                                              │       │
│   │     小顶堆存K个链表头，每次取最小                               │       │
│   │                                                                  │       │
│   │  3. 数据流中位数                                                 │       │
│   │     大顶堆存较小一半，小顶堆存较大一半                          │       │
│   │                                                                  │       │
│   │  4. 任务调度                                                     │       │
│   │     优先处理某种条件的任务                                       │       │
│   └─────────────────────────────────────────────────────────────────┘       │
│                                                                              │
│   Go 中使用 container/heap:                                                  │
│   ┌─────────────────────────────────────────────────────────────────┐       │
│   │  type IntHeap []int                                             │       │
│   │  func (h IntHeap) Len() int           { return len(h) }         │       │
│   │  func (h IntHeap) Less(i, j int) bool { return h[i] < h[j] }    │       │
│   │  func (h IntHeap) Swap(i, j int)      { h[i], h[j] = h[j], h[i]}│       │
│   │  func (h *IntHeap) Push(x any)        { *h = append(*h, x.(int))│       │
│   │  func (h *IntHeap) Pop() any {                                  │       │
│   │      old := *h; n := len(old); x := old[n-1]                    │       │
│   │      *h = old[:n-1]; return x                                   │       │
│   │  }                                                              │       │
│   └─────────────────────────────────────────────────────────────────┘       │
│                                                                              │
└─────────────────────────────────────────────────────────────────────────────┘
```
