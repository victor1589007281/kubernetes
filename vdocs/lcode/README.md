## 🎯 核心算法模式

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                            核心算法模式                                      │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│   1. 双指针模式                                                              │
│   ┌─────────────────────────────────────────────────────────────────┐       │
│   │  [L] ──────────────────────────────────────────────────── [R]   │       │
│   │   ↓                    相向/同向移动                        ↓    │       │
│   │  适用: 有序数组、链表、字符串匹配                                │       │
│   └─────────────────────────────────────────────────────────────────┘       │
│                                                                              │
│   2. 滑动窗口模式                                                            │
│   ┌─────────────────────────────────────────────────────────────────┐       │
│   │  [    窗口    ]──────────────────────────→                      │       │
│   │   left    right                                                  │       │
│   │  适用: 连续子数组/子串问题                                       │       │
│   └─────────────────────────────────────────────────────────────────┘       │
│                                                                              │
│   3. 二分查找模式                                                            │
│   ┌─────────────────────────────────────────────────────────────────┐       │
│   │  [left]─────────[mid]─────────[right]                           │       │
│   │                   ↓                                              │       │
│   │              比较并缩小范围                                       │       │
│   └─────────────────────────────────────────────────────────────────┘       │
│                                                                              │
│   4. 回溯模式                                                                │
│   ┌─────────────────────────────────────────────────────────────────┐       │
│   │              [选择]                                              │       │
│   │             /  |  \                                              │       │
│   │          [a] [b] [c]  ← 递归探索                                │       │
│   │           ↓   ↓   ↓                                              │       │
│   │         撤销选择（回溯）                                         │       │
│   └─────────────────────────────────────────────────────────────────┘       │
│                                                                              │
│   5. 动态规划模式                                                            │
│   ┌─────────────────────────────────────────────────────────────────┐       │
│   │  dp[i] = f(dp[i-1], dp[i-2], ...)                               │       │
│   │    ↑                                                             │       │
│   │  状态转移方程                                                    │       │
│   └─────────────────────────────────────────────────────────────────┘       │
│                                                                              │
└─────────────────────────────────────────────────────────────────────────────┘
```
